How do I get my page HTML?

In a desktop browser, open your public page, use View Page Source, then copy the source here. The exact menu varies by browser. This temporary source-only workflow does not include changes created by scripts. Remove private information first. For a quick demonstration, choose Try a sample.

Processed in this browser. No uploads, analytics, persistent storage, or AI/model calls. Two run summaries stay in memory for comparison; reset or close to clear. Source is never executed. Maximum 150 KB and 1,500 elements.
