This preview adds copyable source-grounded seed drafts and limited structural observations alongside the existing TCC release-receipt loop. It is free to use and runs in your browser without uploads or model calls. Two run summaries stay in memory until reset or close. No persistent history.

Title/description selection and frequent content terms use lexical overlap with the stated purpose/audience. They are not validated semantic SEO advice, measured search demand, or rankings. Review all drafts. URL fetching, live reachability, CSS rendering/accessibility of submitted sites, full validation and SEO outcomes are not implemented. HTML is treated as inert source; observed structural absence is not a full compliance result.

Verification: controlled Chrome fixtures covered seeded defects, valid b/i, denied-clipboard selectable fallback, exact report download, repaired/persisting findings, changed-scope refusal, lexical intent influence without invented terms, byte/tag limits, inert hostile markup with no external requests, viewport overflow at390/768/1440, keyboard sample/review/reset, and preservation of the existing release decision/receipt/refresh flow. This is bounded verification, not comprehensive security or accessibility certification. See SEO_OPTIMIZER_V02_TEST_RESULTS.json.
